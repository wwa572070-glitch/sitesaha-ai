# 公开标准来源

本目录保存 SiteSaha AI 使用的公开标准来源。

- `jncc/`：济南市住房和城乡建设局公开附件。
- `openstd/`：国家标准全文公开系统的标准元数据。
- `normalized/`：用于构建本地 SQLite 知识库的 Markdown 文本。
- `acquisition.json`：最近一次采集时间和访问策略。

`scripts/fetch_public_standards.py` 只下载公开附件，不绕过验证码、登录、
付费墙或其他访问控制。OpenStd 下载入口需要验证码时，本程序只保存标准编号、
名称、状态和官方入口，不复制受限全文。

公开下载不等于可以任意再分发。正式比赛提交、公开发布或商业部署前，应再次核对
标准版权、网站使用条款和项目授权。扫描版 PDF 或旧版 DOC 无法可靠提取正文时，
系统会保留来源说明，但不会用推测内容补全标准条款。
